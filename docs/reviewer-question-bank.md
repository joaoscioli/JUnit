# Reviewer Question Bank

Use these questions to prepare for a technical walkthrough.

## Questions To Expect

- What behavior does this test protect?
- Why is this a unit test instead of an integration test?
- Where are mocks useful and where do they hide risk?
- Which edge cases matter most for this service?
- How would a failing test help a developer debug quickly?

## Strong Answer Direction

Anchor answers in observable behavior, clear test boundaries, readable failures,
and tests that support refactoring instead of only increasing coverage.
