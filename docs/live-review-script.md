# Live Review Script

Use this script when sharing the repository during an interview.

## Opening

This repository shows how I design tests to protect business behavior and reduce regression risk.

## Walkthrough order

1. Start with `README.md` to define the testing scope.
2. Show a simple unit test with clear naming.
3. Show a parameterized or dynamic test.
4. Explain test data choices and assertion style.
5. Close with what would move to integration tests in a real service.

## Strong signal

The repository proves testing judgment, not only familiarity with JUnit annotations.
