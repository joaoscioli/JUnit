# Technical Scope

This file defines what the project is meant to prove and what it does not claim yet.

## In Scope

- JUnit testing strategy.
- Test boundaries and naming.
- Assertions, fixtures, and mocking decisions.
- Interview preparation around test design.

## Out of Scope for Now

- Full application-level test pyramid.
- Large integration environment.
- Performance or load testing.
- Coverage claims without behavioral evidence.

## Scope Statement

The project is scoped to prove testing judgment. The next milestone is adding
more executable examples around edge cases, integration boundaries, and
refactoring safety.
