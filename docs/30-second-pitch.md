# 30-Second Pitch

This repository is a focused Java testing lab with JUnit Jupiter and Mockito.

It demonstrates how I write tests to protect behavior, not only to increase
coverage. The examples cover parameterized tests, dynamic tests, exception
assertions, grouped assertions, edge cases, and mocked external dependencies.

In an interview, I would use this repository to discuss test readability,
business-rule validation, boundary testing, and how tests communicate system
behavior.
