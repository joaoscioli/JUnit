# Interview Evaluation Criteria

Use these criteria to evaluate the project during a technical interview.

## Baseline Signal

- Explains JUnit structure, assertions, and naming.
- Distinguishes unit tests from broader integration concerns.
- Runs or describes the expected test workflow.

## Strong Signal

- Connects tests to observable behavior and edge cases.
- Uses mocks only at meaningful dependency boundaries.
- Explains how test failures should help debugging.

## Senior Signal

- Treats tests as design feedback.
- Balances coverage with risk-based testing.
- Shows how test strategy protects refactoring and long-term maintainability.
