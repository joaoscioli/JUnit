# Pre-Interview Checklist

Use this checklist before presenting the repository.

## Review Before The Call

- Open the fast review path and interview route.
- Prepare one parameterized test and one Mockito boundary test.
- Know which edge cases are protected.
- Be ready to explain why coverage alone is not the goal.

## Be Ready To Show

- `DiscountCalculatorTest`
- `OrderServiceTest`
- `InvoiceServiceTest`
- assertion and boundary documentation

## Strong Close

Explain that good tests reduce risk and make behavior easier to review.
