# Reviewer FAQ

## What should I review first?

Start with the README, test boundaries, assertion strategy, and test style
guide.

## What is the main technical signal?

The project treats tests as design tools that protect behavior and support safe
refactoring.

## What is intentionally unfinished?

More integration-test slices and richer edge-case examples can still be added as
the sample code grows.

## What should we discuss in an interview?

Discuss test boundaries, useful mocking, brittle tests, coverage limits, and
how tests communicate business rules.
