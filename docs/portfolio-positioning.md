# Portfolio Positioning

This is a supporting testing repository in the portfolio.

## What It Proves

- JUnit Jupiter fluency.
- Practical test design around business behavior.
- Mockito usage at external boundaries.
- Attention to edge cases, naming, assertions, and maintainability.

## How To Present It

Present this repository when the interviewer asks how you think about test
quality, not only test quantity.

## Best Interview Angle

Compare a parameterized test with a Mockito service test and explain what each
one protects.
