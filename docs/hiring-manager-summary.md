# Hiring Manager Summary

This repository supports the portfolio by showing testing discipline.

## Why It Matters

It demonstrates that tests are written to protect behavior, boundaries, and
business rules rather than only to increase coverage numbers.

## What To Notice

- Parameterized tests for business-rule variation.
- Mockito examples around external dependencies.
- Edge-case coverage for validation and money-related calculations.
- Documentation for naming, assertions, test data, and boundaries.

## Interview Signal

This project is useful for discussing test quality, test maintainability,
mocking strategy, and how tests communicate system behavior.
