# Hiring Signal

This repository is meant to support hiring conversations for roles that value
testing discipline and code quality.

## What It Proves

- Ability to write tests around behavior rather than implementation trivia.
- Awareness of unit, mock, edge-case, and integration boundaries.
- Communication of testing strategy as a maintainability tool.

## Role Fit

Best aligned with Java backend, QA-minded engineering, platform, and product
engineering roles where refactoring safety matters.
