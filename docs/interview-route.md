# Interview Route

Use this route to navigate the repository during a technical interview.

## Start Here

Open the README and explain that this is a focused Java testing lab for JUnit
Jupiter and Mockito.

## Show The Core Examples

Start with `DiscountCalculatorTest` for parameterized edge cases, then
`OrderServiceTest` or `InvoiceServiceTest` for mocked external boundaries.

## Discuss Engineering Judgment

Use the assertion strategy, test naming, and test boundary docs to explain how
tests stay readable, useful, and tied to business behavior.

## Close With The Next Step

Explain that the next useful improvement is an HTTP-boundary integration test
example that connects unit-level discipline to API-level confidence.
