# Deep Dive Prompts

Use these prompts to move from a high-level walkthrough into a deeper technical
conversation.

## Prompts

- Which behavior is most important to protect with tests?
- Which dependencies should be mocked and which should be integrated?
- What edge cases reveal hidden business risk?
- How should test data be named and organized?
- When does coverage stop being a useful signal?

## Strong Discussion Direction

The best answers should connect tests to behavior, debugging, refactoring safety,
and risk rather than treating tests as a mechanical checklist.
