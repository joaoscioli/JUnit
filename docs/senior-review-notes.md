# Senior Review Notes

These notes help a technical interviewer review the project quickly.

## What to Look For

- Tests that describe behavior in business language.
- Separation between unit tests, boundary tests, and integration concerns.
- Examples that explain mocking decisions.
- Documentation that treats test design as engineering design.

## Senior Signals

- Coverage is not presented as the main quality signal.
- Mocks are used around external boundaries, not as a default reflex.
- The repository helps discuss brittle tests and useful failure messages.

## Discussion Angle

Use this project to discuss how tests support refactoring, protect domain rules,
and reduce regression risk in a professional Java codebase.
