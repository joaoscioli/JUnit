# Key Talking Points

Use these points to keep the interview conversation focused.

## Lead With

- Tests protect behavior, not only coverage numbers.
- Parameterized tests are useful for business-rule variation.
- Mockito belongs around external boundaries.

## Go Deeper On

- How assertion messages and test names improve reviewability.
- Why edge cases matter in money and validation logic.
- Where unit tests stop and integration tests should begin.

## Avoid Overclaiming

- Do not say high coverage means high quality.
- Explain what risk each test reduces.
