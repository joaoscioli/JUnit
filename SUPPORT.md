# Support

This repository is maintained as a Java testing lab focused on JUnit and test
design. Questions and suggestions are welcome when they make the examples more
useful for learning reliable automated testing.

## Best Ways To Ask For Help

- Open an issue for unclear test examples, missing assertions, or fragile test
  design.
- Include the test class, expected behavior, and failure output when relevant.
- Prefer small examples that isolate one testing concept.

## Good Issue Examples

- A test name does not explain the behavior under test.
- A fixture makes the example harder to understand.
- A scenario needs boundary, failure, or regression coverage.
- A documentation note would help connect the test to a real engineering habit.

## Out Of Scope

- Debugging unrelated application code.
- Adding large frameworks that distract from the testing concept.
- Support for private projects or real production data.
